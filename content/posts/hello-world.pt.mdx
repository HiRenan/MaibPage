Este é o primeiro post do blog. Criei o site para reunir meu trabalho e registrar o
que aprendo enquanto construo a MAIB. Como o assunto aqui é engenharia de IA, quis
deixar a própria implementação aberta e fácil de conferir.

## O que vou publicar

Vou escrever sobre Claude Code, programação determinística de LLM, arquitetura e
os problemas que aparecem no desenvolvimento. A ideia é publicar o que realmente
usei, incluindo tentativas que não deram certo e decisões que mudaram no caminho.

## Como os posts são publicados

Cada post é um arquivo MDX dentro do repositório. O frontmatter passa por um schema
durante o build; se algum campo estiver errado, o build falha. O arquivo
`lib/posts.ts` lê, valida e ordena os posts:

```ts
import { getAllPosts } from '@/lib/posts';

const posts = getAllPosts('pt'); // ordenados por data, já validados
```

O pipeline também aplica o destaque de código e mantém uma largura confortável
para leitura. Todo o código do site está aberto no
[repositório](https://github.com/HiRenan/MaibPage). Quando alguma decisão daqui
render uma lição útil, ela vira post.
